# Луг

Менеджер модов для Stardew Valley на Windows. Можно ставить и обновлять моды, переключать сборки и делиться ими в ZIP.

[Скачать Луг](https://github.com/Shyflyadka/stardew-lug/releases/latest/download/Stardew-Lug.zip)

Распакуй архив и запусти `StardewLug.exe`. Если Луг не нашёл игру, укажи её папку в настройках. SMAPI ставится из программы.

Чтобы добавить мод вручную, открой **Моды → Папка модов**. Скопируй туда распакованную папку мода с `manifest.json` и нажми **Обновить список**. Для архива есть кнопка **Установить мод**.

Сборки скачиваются в **Сборки → Публичные сборки**. Чтобы выложить свою, открой **Сборки → Опубликовать сборку**. При первой публикации Луг попросит публичный репозиторий GitHub с темой `stardew-lug-pack` и токен с правом `Contents: Read and write` для этого репозитория. Дальше архив загружается из Луга.

Для обновления программы нажми **Обновления → Обновить Луг**. Если нужно указать источник, выбери GitHub и введи `Shyflyadka/stardew-lug`.

Чтобы собрать программу из исходников, запусти `build.ps1` в PowerShell.
