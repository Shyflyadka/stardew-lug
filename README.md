# Луг 1.5 · менеджер модов Stardew Valley

Открой `StardewLug.exe` на Windows 10 или 11. При обновлении закрой старое окно и замени EXE. Текущая библиотека появляется как **Основная сборка**.

## Обновление Луга

Начиная с версии 1.5, используй **Обновления → Обновить Луг**. Если рядом с EXE лежит свежий `Stardew-Lug.zip`, Луг предложит использовать его. Источник можно один раз выбрать в **Настройки → Источник обновлений Луга**. Подходит стабильный путь к ZIP на диске или доверенный публичный репозиторий автора.

Чтобы раздавать обновления через GitHub, публикуй стабильный релиз с номером версии EXE в теге, например `v1.5.1`, и приложи `StardewLug.exe` или `Stardew-Lug.zip`. Луг сверяет контрольную сумму SHA-256 из данных релиза и версию внутри файла, затем перезапускается. Если новая версия не завершила запуск, Луг возвращает прошлый EXE.

## Установка SMAPI

Кнопка **Поставить SMAPI** скачивает последний стабильный релиз из официального репозитория Pathoschild и устанавливает его в папку Stardew Valley. Луг ищет игру в библиотеках Steam. Если поиск не сработал, укажи папку с `Stardew Valley.exe`. После установки эта кнопка называется **Обновить SMAPI**.

Управление SMAPI всегда есть в разделе **Обновления**. Вверху окна кнопка появляется, когда SMAPI нужен для запуска или доступна новая версия.

## Перенос из SDV MO2

Если библиотека пуста, нажми **Импорт из MO2**, выбери профиль и нажми **Импортировать**. Луг копирует моды в свою папку, учитывает включённые записи, приоритет файлов и папку `overwrite`. Кнопка **Запустить игру** открывает SMAPI с активными модами Луга.

## Обмен сборками

1. Во вкладке **Моды** нажми **Поделиться сборкой**, выбери, включать ли `config.json`, и сохрани ZIP.
2. Передай ZIP. Внутри есть Луг и файлы всех установленных модов. Архив сохраняет состояние включённых и выключенных модов.
3. Получатель может распаковать ZIP и открыть вложенный `StardewLug.exe`. В установленном Луге достаточно выбрать **Сборки → Импорт ZIP**.

Предпросмотр сравнивает состав и версии с активной сборкой и подсвечивает проблемы с зависимостями. Перед применением пресета Луг показывает, какие моды включатся и выключатся.

Для запуска получателю нужна Stardew Valley. SMAPI можно поставить из Луга. В упаковку входят папки модов, категории и пресеты. Перед отправкой проверь, разрешают ли авторы передавать файлы модов. Настройки отдельных модов могут содержать личные данные.

## Сборки, категории и пресеты

- **Сборки → Мои сборки** позволяет создать пустую сборку, скопировать текущую или переключиться между сборками. Импорт из ZIP и публичный каталог создают отдельную сборку.
- **Моды → Категории** фильтрует текущую сборку. Создай свою категорию кнопкой слева и назначь её в карточке мода. С Ctrl или Shift можно выделить несколько строк и назначить категорию сразу им всем.
- **Пресеты модов** сохраняют включённость модов текущей сборки. Например, можно сохранить отдельный набор для кооператива и переключаться между ним и одиночной игрой.

## Публичный каталог

Луг ищет публичные репозитории GitHub с темой `stardew-lug-pack`. Открой **Сборки → Публичные сборки** и выбери публикацию или вставь ссылку на репозиторий, конкретный релиз либо файл релиза. Архив скачивается и устанавливается из приложения.

Для публикации выбери **Сборки → Мои сборки → Подготовить релиз**. Сохрани `.lugpack.zip`, добавь тему `stardew-lug-pack` в своём публичном репозитории на GitHub и прикрепи архив к обычному релизу. Ссылка работает после публикации, поиск по теме зависит от индекса GitHub.

Скачанные через каталог сборки запоминают выпуск GitHub. Луг проверяет новые выпуски при запуске и по кнопке **Проверить обновления**. Новые версии показаны в **Обновления → Сборки**. Новый выпуск устанавливается отдельно от прежней сборки.

## Обновление и восстановление модов

Кнопка **Обновить пакетом** подготавливает архивы с однозначной версией и сохраняет снимок сборки перед применением. Прямое пакетное скачивание Nexus требует Premium. Если в архиве несколько вариантов или контент одного мода зависит от выбора файла, Луг предложит обновить его вручную.

В **Обновления → Снимки сборки** можно вернуть версии модов, их настройки, категории, пресеты и включённость из снимка. Снимок хранится на диске в данных текущей сборки.

Команда **Разобрать проблемы** показывает конкретную зависимость или требуемую версию SMAPI. Выключенную зависимость можно включить из того же окна. Если зависимость отсутствует, Луг ищет её страницу в базе SMAPI.

## Как скачивать и обновлять

| Источник | Действие |
| --- | --- |
| Nexus Mods | В настройках нажми **Получить API-ключ**, скопируй личный ключ и вставь его через **Подключить аккаунт**. В каталоге можно искать по названию, ID или ссылке. |
| Бесплатный Nexus | Выбери файл, разреши принимать ссылки Nexus и подтверди скачивание на сайте. Луг скачает и установит архив. В настройках можно вернуть предыдущий обработчик ссылок. |
| Nexus Premium | Выбери файл и нажми **Скачать и установить**. |
| GitHub | В каталоге нажми **GitHub…**, вставь ссылку на репозиторий и выбери архив из выпуска. |
| Локальный архив | Добавь ZIP, 7z или RAR через **Установить мод** на экране **Мои моды**. |

Во вкладке **Обновления** нажми **Проверить обновления**. Луг покажет рекомендации SMAPI. Обновление сверяет идентификатор мода, переносит `config.json` и сохраняет прежнюю версию. В карточке мода можно выбрать **Вернуть прошлую версию**.

## Карточки и совместимость

Нажми на мод, чтобы справа увидеть описание из его файлов. При подключённом Nexus там же открывается описание со страницы мода. Вкладка **Аддоны** показывает установленные контент-паки и зависимости, дополнительные файлы Nexus и моды, которые указали этот мод в своих требованиях.

Раздел **Совместимость** проверяет дубли, зависимости и минимальные версии Stardew Valley и SMAPI. Кнопка **Сверить с базой SMAPI** показывает известные проблемы, а **Последний запуск** выводит список модов, пропущенных SMAPI в журнале этой сборки. Конфликты, возникающие только во время игры, могут потребовать проверки в самой игре.

Данные и резервные копии находятся в `%LOCALAPPDATA%\StardewLug`. Кнопка **Папка данных** открывает её из приложения. Личный ключ защищён средствами Windows для твоей учётной записи.

В разделе **Настройки** можно отключить анимации кнопок, включить компактные списки, настроить подтверждение запуска и сворачивание «Луга» при запуске игры. Раздел **Файлы и диагностика** открывает папку активной сборки и журналы SMAPI.
